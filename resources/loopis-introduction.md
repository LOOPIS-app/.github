# 🌈 LOOPIS introduction
**Basic info about our organization, concept and work.**

## 🧾 Organization
[LOOPIS](https://loopis.org) is a non-profit organization founded in 2023 in Bagarmossen, Stockholm, Sweden. Our goal is to contribute to a happier and more sustainable future.

## ♻ Concept
We make circulation of stuff in a neighborhood as simple and fun as possible. [LOOPIS.app](https://loopis.app) is a web application combined with a physical locker for exchanging items, creating a hassle-free experience for our members.

## 💾 Tech stack
We use WordPress Multisite to run our web application, with separate sites for every locker in use. WordPress functionality is heavily customized by developing our own [components](https://github.com/orgs/LOOPIS-app/repositories) (plugins + theme). Programming languages used are PHP, HTML, CSS, and JavaScript.
